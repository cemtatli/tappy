# Tappy v0.2.0

A downloadable Chrome Manifest V3 extension for browsing and organizing your own X bookmarks. The interface is in Turkish.

## Changes

- Combine text search with author, publication-date range, image presence, and minimum likes.
- Apply the same filters to Grid, Canvas, and collections. Date ranges include the entire final day in your local timezone.
- See the filtered bookmark/image count and clear all search filters in one action. Search covers locally loaded records.
- Include installation instructions and the MIT license in the ZIP; provide a SHA-256 checksum alongside it.

## Install

Download **tappy-0.2.0-chrome.zip** below, extract it to a permanent folder, open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**. Select the folder containing `manifest.json`, sign in to X in the same profile, and open Tappy from the toolbar.

For upgrades, export important data first, replace the files in your existing installation folder, then click **Reload** on the extension card. Do not remove the extension or clear its storage to upgrade. See `INSTALL.md` inside the ZIP for details.

This is a **GitHub release**, not a Chrome Web Store listing. Updates must be installed manually. Your bookmarks remain on your device; X API changes may require reconnecting or refreshing connection settings. Live X account sync was not tested as part of this release; automated tests use fixtures and mocks.
